# Ismael Araújo — Arquivo pessoal

Site estático em HTML, CSS e JavaScript puro.

## Estrutura
- `index.html`: página inicial / índice editorial.
- `pages/projetos.html`: projetos de tecnologia.
- `pages/cbmce.html`: arquivo independente sobre o concurso CBMCE.
- `pages/politica.html`: caderno de política, história e sociedade.
- `pages/sobre.html`: apresentação e diretório de redes.
- `css/style.css`: identidade visual e responsividade.
- `js/main.js`: menu mobile e ano automático.

## Executar localmente
Abra a pasta no VS Code e use uma extensão como Live Server, ou abra `index.html` diretamente no navegador.

## Antes de publicar
1. Troque os links de redes sociais e e-mail de exemplo.
2. Substitua os textos marcados como amostra/rascunho por conteúdo revisado.
3. Adicione as fontes oficiais e links definitivos na área CBMCE.
4. Revise o conteúdo e teste a navegação em telas pequenas.
